## Reportando uma vulnerabilidade

Não abra uma issue pública para vulnerabilidades. Use o recurso privado de Security Advisories do repositório e inclua impacto, reprodução mínima e versão afetada.

Nunca envie sessão do WhatsApp, pairing code, telefone, token, banco de mute ou credenciais. Substitua identificadores reais por valores fictícios.

O projeto usa um provider não oficial e não pode eliminar riscos de bloqueio de conta ou mudanças no protocolo do WhatsApp.
